# NeuroAdapt · public preview

Static preview of the NeuroAdapt website: an AI tutor that adapts each lesson to a continuous attention signal from EEG.

- `index.html` — the one-page site
- `brain.js` — the 3D brain map used on the page (bundled three.js scene)
- `explainer.html` — the six-scene animated explainer on its own

Open `index.html` in a browser, or view it on GitHub Pages. All data shown on the site is sample data.
